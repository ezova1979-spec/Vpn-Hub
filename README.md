# VPN Hub — Android

Тёмный Flutter-клиент для импорта и управления sing-box профилями.

## Сборка APK через GitHub Actions

1. Создай пустой репозиторий GitHub.
2. Распакуй **содержимое** этой папки в корень репозитория (папки `android`, `lib`, `.github` и файл `pubspec.yaml` должны лежать непосредственно в корне).
3. Сделай Commit changes в ветку `main`.
4. Открой вкладку **Actions** и выбери workflow **Build VPN Hub APK**. При первом push он также запустится автоматически.
5. Дождись зелёной отметки и открой завершённый запуск workflow.
6. Внизу страницы скачай **VPN-Hub-APK** в разделе Artifacts. Внутри будет `app-release.apk`.

Для повторной сборки открой Actions → Build VPN Hub APK → Run workflow.

Чтобы автоматически создавать GitHub Release, создай и отправь тег вида `v0.1.0`.

## Что включено

- Тёмный интерфейс VPN Hub.
- Импорт профилей из буфера обмена и файлов.
- Управление VPN через Android VpnService посредством плагина `sing_box`.
- Протоколы, которые поддерживает используемая версия sing-box: VLESS, VMess, Trojan, Shadowsocks, Hysteria2, TUIC и обычный WireGuard.

## Важно о совместимости

Этот исходник не обещает поддержку всех форматов HAPP/Incy. Подписки и ссылки импортируются только в тех форматах, которые умеет парсер `sing_box`. AmneziaWG и Cloudflare WARP не заявляются как поддерживаемые в этой сборке: для них нужны отдельные совместимые реализации/движки. APK нужно проверить на устройстве с реальным профилем и подтвердить системный запрос Android на создание VPN-подключения.

Минимальная версия Android в проекте — Android 7.0 (API 24). GitHub Actions собирает APK; он не может проверить доступность твоего VPN-сервера или валидность приватного профиля.

## Требования

- GitHub account и репозиторий с включёнными Actions.
- Сборка выполняется в GitHub-hosted Ubuntu runner; локально Android Studio не нужна.
